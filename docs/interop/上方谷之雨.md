# 上方谷之雨

2026-10-15：新增共享联动事件 `ShangFangGuZhiYu`（`YJCM_EVENT_SHANG_FANG_GU_ZHI_YU`），无角色限制，仅在一将成名与至少一个已成功加载且注册了指定奖励牌的伙伴同时启用时加入事件池。

| 选择 | 奖励 | 出现条件 |
| --- | --- | --- |
| 是梦 | 一枕清梦 | 事件出现时始终可选 |
| 是叹息 | 上方谷之叹 | 孙乾宇宙已加载且卡牌可用 |
| 是天意 | 比夷陵之火还好啊 | 新三国已加载且卡牌可用 |
| 是历史 | 七星灯 | 事件出现时始终可选 |

每个选项只发放自己的奖励；卡牌通过原生 `RunState.CreateCard(canonicalCard, Owner)` 和 `CardPileCmd.Add(..., PileType.Deck)` 进入持有者永久牌组。事件选项带奖励悬浮说明。仅安装文件但禁用、加载失败、或旧版尚无奖励牌时不显示对应选项。

## 七星灯

- 事件专属遗物 `QiXingDeng`（`YJCM_RELIC_QI_XING_DENG`），不加入普通奖励/商店候选。
- 整局限一次，使用原生 `ShouldDieLate` / `AfterPreventingDeath`。只保护持有者，先记录已消耗，再以原生恢复流程从 0 恢复至 7 点生命（不超过原生生命上限），在战斗中获得 7 点能量并抽 7 张牌。战斗外只执行可适用的救命恢复，不访问不存在的战斗牌堆和能量。
- `[SavedProperty] WasUsed` 跨战斗和读档保留，触发后显示已消耗状态，不在回合/战斗开始重置。
- 1.2.2：正常出牌阶段救命立即获得7能量；敌方回合、本人回合结束/结束自动出牌阶段触发时，改为原生 `EnergyNextTurnPower`，在持有者下次能量重置后获得7点并移除此状态。回血和抽牌仍立即结算，不保留其他来源的剩余能量，也不重复发放7点。
- 若当前有原生动作，抽牌使用该动作的选择上下文；否则使用 Hook 上下文，只等待完成或暂停，不在原动作内等待新排队动作。抽牌数量与手牌上限继续遵循游戏规则。
- 作者确认最终名称“七星灯”，风味为“魏延将军，走慢点！”。事件与遗物原图只保留本地，受素材排除规则保护。

## 事件画面

背景使用 `Yjcm/scenes/shang_fang_gu_event_background.tscn` 和同名 `.gd`：原图等比例放大铺满顶部 HUD 以下的事件区域，顶部对齐、优先裁去下部衣摆，避免再次裁掉人物头部；不再使用左右分区或独立黑色面板。右侧文字区通过横向半透明渐变压暗，原始图片文件不变。`ShangFangGuEventLayoutPatch` 仅在本事件中替换原生肖像显示，清除原图的最小尺寸约束；原生正文、选项、投票、悬浮说明和选择回调保持不变，背景不拦截输入。

## 验证

`tests/check_shangfanggu.ps1 -Variant stable|beta` 覆盖界情势标准模型身份/图鉴集合、四种伙伴组合、缺卡旧版、七星灯持有者/一次性规则、持久化声明及事件奖励路径；完整包审计额外验证事件图、遗物图标及本地化。

回合外能量覆盖两版各玩家阶段的分流规则；`CollaborationTests/LampEnergyCases` 调用实际原生 `EnergyNextTurnPower.AfterEnergyReset`（命令副作用模拟），验证队友不领取、3点基础能量加7点奖励后为10、状态移除及后续回合不再发放。

`tests/check_shangfanggu_layout.gd` 在 Godot 中加载真实背景场景，检查 1920×1080、1280×720、2560×1440、2560×1080、1600×1200 下的铺满、顶部对齐、无比例失真、渐变压暗与鼠标穿透。它验证场景几何，不代替实际游戏中的画面确认；带渲染器运行并传入 `-- --render` 可输出纯背景预览。

这些离线检查不等于真实三模组共同运行、实机 UI、存档重载和联机验证，发布前仍需合作测试。
