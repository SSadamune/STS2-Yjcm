# 武诸葛亮联动卡牌

两张牌均为武诸葛亮普通卡池的罕见牌，不复制到威董卓卡池，无须安装伙伴模组才能获得；卡旁“联动”悬浮框标注来源。

- 孙乾-水火无敌：2 费攻击，7/11 点伤害。火攻与格挡取本次攻击的实际生命伤害（原生 UnblockedDamage 减去 OverkillDamage，不含格挡）。先施加火攻，再获得等量格挡；格挡不重复受敏捷或脆弱修正。被完全格挡时不发放；死亡目标不再施加火攻。
- 新三国-水火兼容：2/1 费能力。当你具有原生虚弱时，攻击伤害倍率改为 1.25；具有原生易伤时，受到的攻击伤害倍率改为 0.5；具有原生脆弱时，从卡牌获得的格挡倍率改为 1.25。三项原生减益的层数、施加/移除与持续回合不变，新获得的减益同样适用。重复使用此能力不重复翻转或叠乘，不影响队友/敌人的减益，不影响无来源特殊生命损失。

卡图与语音原件来自本地素材目录，不纳入公开仓库。`tools/prepare_collaboration_cards.ps1` 原样复制成品卡图，将两段 MP3 转为 48 kHz 单声道 PCM WAV，并在素材的“语音素材/武诸葛”目录保留 WAV。

验证：`tests/check_collaboration_cards.ps1 -Variant stable|beta` 包含卡牌元数据检查，以及匹配游戏的 .NET 9 进程内真实 Harmony 补丁测试；这不替代游戏内交互或联机验证。
