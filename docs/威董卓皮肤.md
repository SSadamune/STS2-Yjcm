# 威董卓·泰山崩石

选人页右上角的皮肤栏可在“威董卓”和“泰山崩石”之间切换，立即刷新大厅背景，并记住本机选择。皮肤不创建新角色、不修改卡牌、遗物、角色ID或数值；与武诸葛亮的皮肤设置相互独立。

来源：用户本地 `素材/图片素材/威董卓皮肤`。原件为两套 Spine 4.0：`beijing`（背景）、`daiji`（人物），每套各两张图集纹理。未改动原件；运行副本转换为 4.2.43，位于 `assets/loose/Spine/WeiDongZhuoTaiShan`。

- 大厅：背景按实际底图范围铺满，不按飞石/闪电的外扩范围缩小。人物保持原比例和大小，底部锚点为屏幕高度74%，横向中心锚点53%（2026-10-20依截图先从96%上移22%屏高，再参照原画从X37%右移16%屏宽）；允许上方披风越出裁切区，让脸和上身避开左侧说明框及底部难度栏/角色栏。不影响默认皮肤或战斗位置。
- 战斗与商店：使用人物待机循环，运行副本清除人物分支外6个独立光效槽位，保持头发、披风、刀和身体动画。此项不是此前已撤销的攻击动画；没有添加攻击触发器或伤害/等待逻辑。
- 火堆、头像、联机手势与语音：本次未提供专用版本，保持原有资源，不自行绘制替换。
- 设置键：`WeiDongZhuoSkin`，默认 `classic`；新皮肤值 `tai_shan_beng_shi`。未知/缺少字段回退默认，使用既有全局设置存储，不新增第二个配置文件。与既有武诸葛皮肤一样，这是本机外观选择，不修改联机玩法同步或存档角色身份。

重新准备素材：设置 `WDZ_NODE_MODULES` 为已安装工程开发依赖的node_modules目录，运行 `node tools/prepare_weidongzhuo_skin.mjs [工作区]`。转换器仍使用本地 `_spine_conversion_tools/SpineSkeletonDataConverter.exe`。

验证：双版本 `tests/check_weidongzhuo_skin.ps1`；Godot布局 `tests/check_weidongzhuo_skin_layout.gd`；真实Spine预览 `node tools/preview_taishan_skin.mjs`（仅本地开发服务器，报告写入artifacts）。浏览器预览不代表游戏内或联机实测。
