# 源码仓库与本地资源

公开仓库仅含原创源码、脚本、本地化、文本场景/材质定义和开发文档，不含运行素材或完整成品。CDphantom 的代码许可不授予三国杀素材或原版游戏内容的使用权。

## 本地完整构建需要

- Godot 4.5.1 Mono、.NET SDK 10.0.203、Node.js、PowerShell 7。
- 合法取得对应游戏版本的 DLL，按 dependencies 中的 manifest 和 prepare-dependencies.ps1 准备固定 stable/beta 依赖。
- 合法取得的运行资源，按代码/场景的原路径准备在 mod/Yjcm/Images、mod/WeiDongZhuo/images、mod/images、mod/Yjcm/Audio、mod/Yjcm/audios、mod/Yjcm/Voice 等目录，并准备 mod/icon.svg。
- 松散资源放在 assets/loose/Voice、assets/loose/Spine、assets/loose/MeshAnimation；Spine 图集、纹理、骨架须匹配。图片 .import 等引擎导入旁文件不上传，Godot 在本机重新导入。

mod/src 和 Godot 文本场景/材质保留运行资源路径，但不包含其指向的素材。原有开发机器资源不移动、不删除；.gitignore 只阻止上传。没有资源时，不应把构建/打包失败误当作已公开代码缺少另一套业务工程。

## 无游戏依赖的检查

```shell
node tools/check-repository.mjs
node tools/check-public-source.mjs
node tools/generate_cards.mjs --variant stable --check
node tools/generate_cards.mjs --variant beta --check
cd telemetry
npm test
```

游戏导出、视觉检查、打包和完整回归需要上述本地依赖与资源；公开 CI 不尝试获取素材或游戏二进制，不自动发布成品。
