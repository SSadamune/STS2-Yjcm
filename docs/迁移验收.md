- 遥测 Worker/仪表盘 36 项测试通过，私有 dashboard 配置保留但被 Git 忽略。

一次性迁移脚本及迁移中复制的两份参考 PCK 已清除，额外移除 PCK 419,401,696 字节（约 400 MiB）。后续需要旧包对照时，可显式向 tests/check_migration_pack.mjs 传入保留的当前发布包 PCK。最后完整双目标构建记录为 artifacts/logs/build_20261011_001853。

迁移完成时仓库初始化为 main 分支，尚未上传。恢复旧工程时将上述 ZIP 解压至独立临时目录，按 backup-manifest.json 的路径与 SHA-256 检查；不要直接覆盖现行 Yjcm 工程。
