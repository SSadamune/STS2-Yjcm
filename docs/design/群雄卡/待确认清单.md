## 本轮按上下文作出的实现解释

- “连招技-伤害”暂按“紧邻上一张牌为攻击牌”判断，因为当前游戏牌模型没有独立的“伤害牌”类型。
- 破戎的“重复上一张攻击牌”会完整重放该牌；升级后仅将重放造成的伤害加倍，并加入递归保护，避免破戎互相无限重放。
- 佐军当前为：摸 3 张牌后选择一种模式，并让这 3 张新摸到的牌全部获得“保留”或“本回合 0 费”。
- 附袭升级后：攻击分支为 11 点伤害并施加 2 层虚弱；非攻击分支为自己获得 3 点力量、抽 2 张牌，敌人仍获得 1 点力量。
- 漠猷中的“若为”按“被弃置牌的类型”判断。
- 内伐先抽 3 张再弃 1 张；弃攻击牌时封锁技能并免费打出攻击牌，弃技能牌时反之。
- 驱险在回合结束结算后将生成牌加入手牌。
- 剑道按每次攻击造成伤害计数，多段攻击的每一段均计数；每累计两次触发。
- 试锋只在攻击造成未被格挡的生命伤害时触发。
- 入世随机出的费用、伤害等字段在当场战斗中固定；若游戏支持战斗中保存并重载，需要额外验证这些随机字段能否完整恢复。
- 佐军的两个选项牌仅作为选择界面用的隐藏 Token，不进入牌池，因此不添加群雄/武将标签。
