# 卡牌中心特效（2026-10-09）

原始素材：`素材/各类特效`，原件不改动。当前 17 组均含 `gongji` / `jineng` 两个动画。
运行素材：`威董卓开发/loose_assets/Spine/CardEffects`，77 个文件（包含索引），约 181 MB；不额外嵌入 PCK。
使用现有转换器输出 Spine 4.2.43。许靖的 `chuchang2 .png` 仅在运行副本中改为 atlas 实际引用的 `chuchang2.png`。

## 播放规则

- 公共实现：stable/beta `YjcmCode/Visuals/CardEffectVfx.cs`。
- 在原生 `CombatHistory.CardPlayStarted` 后播放，攻击牌为 `gongji`，技能/能力为 `jineng`；仅匹配本程序集的精确卡牌类型，不匹配选项牌或其他 Mod 的同名牌。
- 自动打出、已有同名衍生牌与董卓复制牌同样适用；同一次牌执行的重复结算不再次播放。每次独立打出正常触发。
- CanvasLayer 中按可见视口中心定位，人物基准最大宽/高占对应视口尺寸 72%，缩放随窗口调整。Spine Y-up 只在中心坐标中转为 Godot Y-down，不翻转图像。
- 谋贾诩的两组（覆谋-阳/肃身、覆谋-阴/入世）按用户截图确认改为全屏场景：缩放取视口宽/高比中的较大者，使参考范围覆盖全屏，保持比例和居中，边缘可自然超出屏幕；其他武将仍为原 72% 基准。
- 以 35% 时刻的可见人物姿态作为居中/缩放基准，忽略超大闪屏图层及神黄忠远处的第二人物作为尺寸参考；原动画所有图层仍保留并播放。避免因 64,000 单位的闪屏或远处人物让主特效缩成小点。
- 不修改伤害/选择/随机数，不等待动画、不启动后台游戏动作。按实际动画时长自动清理，离开战斗时节点随房间释放；快速连续出牌时新特效替换旧特效。旧连招/势魏延特效不修改。
