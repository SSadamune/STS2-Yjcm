# 一键扫荡规则确认单

确认日期：2026-09-23

## 生效范围

- 仅当联机队伍中至少有一名玩家使用本 Mod 角色（武诸葛亮或威董卓）时生效。
- 联机由队伍中 NetId 最小的本 Mod 角色玩家作为控制玩家，并以该玩家的本地设置统一生成结果。
- 最终逃跑名单通过原版 `PlayerChoiceSynchronizer` 同步，其他玩家不使用各自的本地概率重复判定。
- 仅判定进入战斗时已经存在的敌人；战斗中后来召唤的敌人不补判。

## 设置模式

1. **自定义概率**：普通、精英和首领战斗分别设置 0%～100%，步长 1%。默认均为 0%。
2. **每场随机概率**：每场战斗先随机生成一个 0%～100% 的概率，该场所有初始敌人使用同一概率。
3. **一键扫荡**：该场所有初始敌人必定逃跑，包括精英和首领。

无论使用自定义还是每场随机模式，每名初始敌人都独立掷骰判定，因此同一场多敌人战斗中可能只有部分敌人逃跑。

## 结算与表现

- 逃跑敌人先显示“跑啊！”气泡，再向屏幕右侧移动并退出战斗。
- 逻辑复用原版 `CreatureCmd.Escape`，敌人记为逃跑而不是死亡。
- 扫荡判定与逃跑动画在第一回合所有存活玩家的初始手牌摸取完成后触发；不再在战斗开始钩子中提前执行。
- 逃跑横移动画时长为 1.35 秒，并从 8 条本地化逃跑台词中随机播放一条。
- 逃跑完成后调用原版 `CombatManager.CheckWinCondition`；若已无可继续战斗的主要敌人，则按正常战斗胜利结算并获得该房间原有奖励。
- 原版普通战斗会按逃跑比例扣减金币；扫荡赶跑的敌人在金币比例计算中按已击败处理。只有原生机制逃跑的敌人才继续扣减金币，避免全员扫荡时金币奖励变成 0。
- 判定随机数不消耗游戏运行种子的 `RunRng`，避免关闭功能或未命中时改变其他原版随机结果。
